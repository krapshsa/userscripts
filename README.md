# Userscripts

A collection of Tampermonkey userscripts for adding useful features to web applications.

## Scripts

- [ChatGPT Bulk Delete](./chatgpt-bulk-delete/README.md) - Select and delete multiple ChatGPT conversations at once.
- [Gemini Bulk Delete](./gemini-bulk-delete/README.md) - Select and delete multiple Google Gemini conversations at once.
- [NovelAI Auto Generate](./novelai-auto-generate/README.md) - Toggle automatic image generation on NovelAI.
- [Twitch Auto Claim Channel Points](./twitch-auto-claim-channel-points/README.md) - Automatically claim Twitch channel point bonuses.

## Installation

1. Install [Tampermonkey](https://www.tampermonkey.net/) in your browser.
2. Open the `.user.js` file for the script you want to use.
3. Copy its contents into a new Tampermonkey script and save it.
4. Open the supported website and refresh the page.
